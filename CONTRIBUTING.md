# Contributing to Culminating Point

Thanks for taking the time to file something. Feedback shapes the game. You can write in English or Italian.

## What goes where

| You want to… | Use this |
|---|---|
| Report something broken or wrong | [Bug template](https://github.com/Culminating-Point/culminating-point-feedback/issues/new?template=bug.yml) |
| Ask for something missing or different | [Feature template](https://github.com/Culminating-Point/culminating-point-feedback/issues/new?template=feature.yml) |
| Say a unit, map, rule or outcome does not fit the war | [Balance template](https://github.com/Culminating-Point/culminating-point-feedback/issues/new?template=balance.yml) |
| Ask a usage question | [Discussions](https://github.com/Culminating-Point/culminating-point-feedback/discussions) or hello@culminating-point.com |
| Disclose a vulnerability | security@culminating-point.com, see [SECURITY.md](SECURITY.md) |

## Filing well

A useful report contains, at minimum:

- **What you did**: the orders you gave, the scenario and the side
- **What happened**: the behavior, with a screenshot if you can
- **What you expected**: what would have been correct
- **The link**: the game keeps its state in the address bar, so a pasted link reopens what you saw
- **The version**: shown on the title screen

Please search the [open issues](https://github.com/Culminating-Point/culminating-point-feedback/issues) before filing. A thumbs-up on an existing report counts more than a duplicate.

## What we'll do

- Triage cadence: **weekly**. Issues get a `triage` label until reviewed.
- `accepted` means it is on the work list. `wontfix` means we won't act, with a reason. `needs-info` means we need something from the reporter.
- No SLA. The game is run by a solo maintainer; responsiveness is best-effort.
- We close issues that are off-topic, duplicates or unactionable. Disagreement is welcome: argue your case in the thread.

## Code contributions

There is no code in this org's public repos today, and the game is closed-source for now. If you want to build something around it, open an issue first to discuss.
