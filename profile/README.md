# Culminating Point

> Every kilometer gained is a kilometer to supply.

Culminating Point is a real-time strategy game of the war in 1941, where logistics decides it: depots, crates and green trucks set how far a division can go. It runs in the browser, in English and Italian.

**[culminating-point.com](https://culminating-point.com)** · **[Manual](https://culminating-point.com/manual/)**

---

## What's in this org

- **[culminating-point-feedback](https://github.com/Culminating-Point/culminating-point-feedback)**: the public issue tracker. File bugs, request features, report balance or history problems. There is no code there; the maintainer triages weekly.

The game itself is closed-source for now.
