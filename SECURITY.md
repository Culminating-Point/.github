# Security Policy

## Reporting a vulnerability

**Email: [security@culminating-point.com](mailto:security@culminating-point.com)**

Please **do not** open a public issue for security-sensitive reports.

In your report, include where possible:

- A description of the vulnerability and its impact
- Steps to reproduce, ideally with a minimal proof of concept
- The affected page, file or build (browser, installed app, desktop app) and its version
- Whether you have disclosed this elsewhere

## What you can expect

| Stage | Target |
|---|---|
| Acknowledgement | within 72 hours |
| Initial assessment | within 7 days |
| Status updates | weekly until resolved |
| Public credit | on request, after the fix |

The game is run by a solo maintainer, so there is no formal SLA, but every report is read personally.

## Scope

In scope:

- `culminating-point.com` and the game served from it
- The desktop app
- Saved games and what the game stores on your device

Out of scope:

- Findings against third-party providers the site depends on (Cloudflare, GitHub): report them to the provider
- Denial of service by traffic volume
- Social engineering
- Issues requiring a rooted device, a malicious browser extension or physical access
- Reports from automated scanners with no manual validation

## Safe harbor

We will not pursue legal action against researchers who:

- Make a good-faith effort to avoid privacy violations, data destruction and service interruption
- Only interact with accounts and devices they own or have permission to test
- Give us a reasonable window to respond before any public disclosure
- Do not exploit a finding beyond what is needed to demonstrate it
